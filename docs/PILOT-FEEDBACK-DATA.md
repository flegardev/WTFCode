# Pilot feedback data contract (before implementation)

Optional feedback stores only the authenticated user ID, a category, a chosen product area, a 1–5 usefulness rating and submission time. There is no free-text, source-code, credential, browsing-history or third-party analytics field. The form explains this before submission. It is voluntary and does not affect trial access. It is exported with the account, cascades on deletion and is pruned after 30 days by maintenance. Only an authorized server operator can see aggregate counts through the private CLI; individual follow-up requires separate founder approval and participant agreement. This does not establish a legal basis or GDPR compliance; the operator must confirm the notice, identity and retention policy before inviting anyone.
