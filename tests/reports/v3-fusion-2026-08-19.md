Command: `php tests/FusionBenchmark.php`

The preserved V2 baseline recorded regression pass/fail and self-dogfood counts, not fact-level predictions, so V2 precision and recall cannot be reconstructed honestly.

## Fusion value observed

V3 Native and fused V3 both recovered every curated fact. Fusion did not improve recall on this small set and was substantially slower. It did add evidence depth:

| Evidence quality | V3 Native | V3 fused |
| --- | ---: | ---: |
| Symbols | 55 | 84 |
| Relationships | 57 | 97 |
| Resolved relationships | 21 | 30 |
| Confirmed facts | 0 | 77 |
| Multi-engine facts | 0 | 27 |

Peak PHP memory reported by this fixture benchmark was 6,291,456 bytes. This does not include child-process memory.

Conclusion: fusion adds independently confirmed facts and semantic relationships, but this benchmark does not support claiming a native recall or curated-precision gain. Larger public-repository and human usefulness review remain separate gates.
